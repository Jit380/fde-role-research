# FDE field notes

Concise research on real forward-deployed engineer internships and full-time roles. Six primary postings, checked November 12, 2026. US-focused, intentionally small sample; not a market census.

**[Read the site](https://jit380.github.io/fde-role-research/)**

## Run locally

Requires Node.js 22+ and npm.

```sh
npm ci
npm run docs:dev
npm run docs:build
npm run docs:preview
```

GitHub Pages publishes from the deployment workflow on pushes to `main`. The site lives in `docs/`; primary links and verification limits are in `docs/sources.md`.

## Editorial structure

Start here → internship or full-time evidence → skills and distinctions → source audit. Repeated fields reduce comparison effort; primary facts and editorial interpretation are labeled separately. No marketing landing page, application tracking, or personal data collection.
