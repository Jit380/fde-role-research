## Evidence you can prepare

*Editorial suggestions inferred from these duties; these are not employer application requirements.*

1. **One end-to-end project:** name the user problem, build the integration, deploy it, and document a failure you fixed.
2. **One customer explanation:** show how you translated a vague request into a scope, tradeoff, and measurable result.
3. **One relevant extension:** evaluations for an AI role; sensors and debugging for a hardware role; an API proof of concept for a commercial deployment role.

For internships, coursework and personal projects can demonstrate foundations. Experienced roles add evidence of sustained production ownership or customer delivery.
